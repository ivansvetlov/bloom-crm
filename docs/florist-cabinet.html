Кабинет флориста

Дизайн-спека · демо-режим · только ПК · 2026-08-02

Исходный сигналзачем

!

Фото-гейт спамит не того пользователя

«Нужно фото букета» сейчас приходит тостом менеджеру, но фото делает флорист в магазине. Для менеджера это шум, для флориста — рабочий список. Вывод: фото-гейт принадлежит кабинету флориста, а не менеджерскому.

Принципыкак строим

  • Консистентность — те же экраны/меню/карточки, что в сборном кабинете, отфильтрованные ролью.
  • Минимум экранов — «Сегодня» не возвращаем (убрано из сборного). Всё в «Заказы».
  • Не оверинженирим — инвентарь, ИИ, курьерское приложение, офлайн — «потом».
  • Пока только ПК — адаптив после подтверждения КП и оплаты.

Карточка заказафлористская

  • Состав + слот, срочность ⚡, оранжевая подсветка за 45 мин до дедлайна
  • Получатель/адрес, текст открытки, комментарий
  • Индикатор времени сборки (сколько уже собирает)
  • Крупный блок фото: «Сфоткать „до“» → подтверждает сборку; предупреждение о размытом фото (можно пропустить)
  • Кнопки: «Начал сборку» → «Собрано» → «Передать курьеру» / «Готов к самовывозу»
  • «Запросить замену у менеджера» (не покидая карточку) · «Вернуть менеджеру» с причиной
  • Нет: оплаты, счетов, полной истории

Поток флористапо шагам

Принят (менеджер / авто)
→ видит в «Заказы» (сорт: ⚡ → дедлайн)
→ «Начал сборку» (карточка: «Уже собирает <имя>»)
→ чекбокс «Все цветы по составу в наличии» (нет → «Запросить замену»)
→ собирает → «Собрано» → фото «до» (сырые цветы)
→ чекбокс «Брак при сборке» (опционально → аналитика потерь)
→ «Передать курьеру» ИЛИ «Готов к самовывозу»
→ заказ уходит из очереди

Не может собрать → «Вернуть менеджеру» + причина → заказ выпадает из очереди, менеджеру уведомление. «Испорчено при сборке» → возврат в очередь как «Пересборка» (без авто-уведомления курьеру и +15 мин).

Уведомлениявизуально, без звука

  1. «Новый заказ в ваш магазин» (с пометкой срочности)
  2. «Заказ приближается к слоту, а фото нет» — за 45 мин, оранжевая подсветка (это то, что раньше спамило менеджера)
  3. «Менеджер вернул заказ на доработку»
  4. Перегруз >15 заказов → «Рекомендуем режим „Только сборка“»
Звуковые триггеры не делаем — в цеху раздражает.

Краевые случаив демо — 4 из 10

1

Цветок закончился, замены нет

«Невозможно собрать» → статус «Требуется звонок клиенту», уходит из очереди, менеджеру уведомление.

2

Клиент отменил, когда флорист начал сборку

Карточка серая «ОТМЕНЁН · подтвердите, что не собираете» → «Подтверждаю, что не собираю».

3

Нет заказов (тишина в цехе)

Экран «тишина» с кнопкой «Позвать менеджера» — закрывает простаивание.

4

Размытое/тёмное фото

Предупреждение «Переснять?» с возможностью пропустить (руки мокрые).

→

«Потом» (не в демо)

ИИ-сравнение фото с составом · офлайн-кэш · курьерское приложение · подзадачи на 2 букета · «передать коллеге» при обеде · авто-+15 мин курьеру · списание инвентаря.

Критерии готовности (демо):
1. Вход под «Флорист» → только «Заказы»/«Чаты»/«Номенклатура» своего магазина.
2. Заказ: Принят → «Начал сборку» (блокировка) → «Собрано»+фото → «Передать курьеру».
3. Без фото кнопка «Передать курьеру» заблокирована с подсказкой.
4. «Вернуть менеджеру» / «Запросить замену» уводят заказ и уведомляют менеджера.
5. Оранжевая подсветка за 45 мин, перегруз >15, экран «тишина».
6. Фото «после», звук, списание, ИИ, офлайн, курьерское — сознательно отсутствуют.
