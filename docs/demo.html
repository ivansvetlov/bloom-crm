Шаблон ответа

Быстрая фраза для диалогов. После сохранения появится над полем ввода.

Бронь по времени

Резерв слота: клиент + (опционально) товар из витрины. Не путать с оплаченным заказом — это «заморозка» времени.

Подтвердить оплату

Фиксируем факт оплаты. Прикрепите документ об оплате (чек, квитанцию, скрин) — без него подтверждение недоступно.

Отменить заказ

Заказ будет отменён. Клиент получит уведомление об отмене в канал связи.
