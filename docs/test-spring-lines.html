Короткий разбор

  • D — pill-пузыри с glass chrome (блик + rim + blur), цвет насыщенный, без бледной прозрачности и без dissolve по бокам.
  • A/B (spring) — «дороже» и живее: наклон в keyframes + вертикальный дрейф. Хорошо как разделитель секций (между hero и неделями / между неделями и CTA).
  • C (наши) — спокойнее, читаемее, уже в бренде. Чуть «лендинговее», меньше «школьного» вау.
  • Если нравится C — бери D в test-dynamic: узнаваемый Bloom, чуть больше жизни, без чужого lime/blue spring.
  • Не мешать spring-line внутри sticky-карточек недель — только между блоками, иначе шум.
