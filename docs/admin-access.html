Обзор доступа

Контур управления правами сети: роли, точки, партнёры, аудит. Отделён от операционного кабинета, чтобы случайно не сломать ACL со смены.

Модель (кратко)

User × Roles (merge max) × ShopScope × PartnerFlag. Уровни: none → own → shop → network | partner.

none own shop network partner
Правило: несколько ролей сливаются permissive (как Espo). Партнёр никогда не получает network / чужие ключи / export ПДн.

Матрица прав

Модуль × уровень доступа. Клик по ячейке циклит: none → own → shop → network. Для партнёрской роли — partner.

none own · свои shop · точка network · сеть partner

Особые действия (boolean)

Поверх level: отмена, цены, ключи, export ПДн…

Точки и scope

Membership user ↔ shop. Директор = network (все). Партнёр = ровно одна изолированная точка.

Shop ≠ только ACL: точка — бизнес-сущность (адрес, каталог, ключ API). Здесь только «кто видит записи точки».

Команды / смены

Опциональный слой Espo Teams: утренняя смена, B2B-группа. Не заменяет shop scope.
