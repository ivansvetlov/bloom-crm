Что выбрать для Bloom

Основной гибрид — B · «Деньги через заказы». Владелец сети смотрит на выручку, а менеджеры — на статусы заказов; B держит обе картины на одном экране и прямо показывает, где застряли деньги (6 новых, 7 принятых, 5 срочных). Прогресс-бары статусов заменяют канбан без канбан-структуры — операционка сохранена, но подчинена финансам.

  • A · «Операционный день» — утренний экран менеджера: очередь «что делать сейчас» без аналитики. Использовать как первый экран рабочего дня, B — как сводку для владельца.
  • C · «Команда и нагрузка» — включать в пиковые дни (8 Марта, Новый год), когда нужно балансировать флористов и точки.
  • D · «Пульс сети» — еженедельный взгляд владельца: тренды 14 дней и топы без лишних цифр.

Итого: для повседневного экрана — B (деньги через заказы), A — как операционная надстройка над ним. C и D — ролевые варианты для пиков и отчётов.
