# Официально vs серое (чаты)

| | Официально | Серое (дешёвая платформа) |
|--|------------|---------------------------|
| WhatsApp | Cloud / Business API | Автоматизация личных номеров |
| Telegram | Bot API | Личные / userbot |
| Стабильность | Высокая | Риск блокировки |
| Цена | За сообщение / диалог | Низкая |
| История | По правилам API | Часто только post-connect |
| Гарантия «год» | Реалистичнее | Слабее |

ТЗ: «платформу прислали» → нужно имя платформы (форма q5).
