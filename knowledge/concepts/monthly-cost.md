# Ежемесячные расходы (pre-sales)

Точная цифра — после ответов на вопросы об объёме. Диапазон в КП (`docs/index.html`):

| Статья | Диапазон |
|--------|----------|
| Сервер и база (РФ) | 2–6 тыс ₽ |
| Хранилище фото | 0.5–3 тыс ₽ |
| Мессенджеры WA/TG/MAX | 0–15 тыс ₽ |
| **Уведомления ВК** | **0–2 тыс ₽** |
| Домен | 0.2–1 тыс ₽ |

**Базовый сценарий:** от **5 500 ₽/мес** (с запасом на VK).

## Заметки
- VK Community API — без поштучной платы VK; резерв на бота/шлюз
- Серые мессенджеры дешевле, но риск бана
- Peak load (8 Марта) двигает сервер вверх
