# Open questions

Критичные для архитектуры / сметы (часть закрывается формой):

1. Официальные vs серые мессенджеры + **название платформы** (ТЗ)
2. Flowwow API: write statuses/photos/catalog, webhooks?
3. Multi-account FW (подтверждено: аккаунт на точку) — ключи, каталоги
4. Модель курьеров + tracking depth
5. #shops, peak orders/day, concurrent managers
6. Источник и чистота клиентской БД
7. **Склад:** Bloom stock vs внешняя WMS
8. Когда ТЗ лояльности
9. Банк/ОФД — только если критично сразу (v1 без)
10. MAX API surface
11. Поддержка после сдачи vs полная передача
