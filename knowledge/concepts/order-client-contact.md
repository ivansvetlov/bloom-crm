# Связь с клиентом по заказу

> **Статус: ОТЛОЖЕНО.** Воркфлоу согласован владельцем 2026-08-02, но реализация отложена до следующей итерации («давай пока отложим, просто запиши»). Не реализовывать в текущей сборке.

## Проблема (крайние события)

1. У клиента, заказавшего на сайте, **может не быть диалога** в мессенджерах.
2. **Номер телефона есть всегда** (обязательное поле оформления), но бывает — **не написать / не дозвониться**.
3. Заказы с сайта или по телефону **обычно с комментарием** клиента — это контекст, который сейчас не живёт как сущность (только строка `o.note`).

Текущая логика в `docs/demo.html` (`orderContacts` + `findOrCreateChatForOrder`):
- Контакты берутся из оформления (телефон→WA, @tg, max, wa).
- **Дыра:** заказ fw без диалога → создаётся подставной чат «Диалог из заказа…», а не реальный outbound.
- **Дыра:** если контактов нет вовсе → список пуст, а кнопка «Перейти в чат» всё равно висит.

## Согласованный воркфлоу (одинаковый для менеджера и флориста)

Ядро — не «канал связи», а **«работа с клиентом по заказу»**. Телефон обязателен → звонок/написать доступно всегда.

| Состояние | Когда | Что видно в карточке (одинаково у менеджера и флориста) |
|---|---|---|
| 🔵 **Диалог есть** | Чат привязан к заказу | «Связь: WhatsApp · диалог есть» + «В чат» |
| 🟡 **Пишем / звоним** | Телефон есть, ответа нет | «Позвонить клиенту» / «Написать в WA» + счётчик попыток |
| 📝 **Комментарий клиента** | `o.note` непустой | Блок «Комментарий клиента» — всегда над «Связью» |

**Переходы:**
```
Заказ прилетел (fw/phone) — номер есть, комментарий опционален
  ├─ есть привязанный диалог → 🔵 «В чат»
  └─ диалога нет → 🟡 «Позвонить» / «Написать в WA» — первый контакт
        ├─ клиент ответил → создаём/привязываем диалог → 🔵
        ├─ не ответил → фиксируем попытку («не дозвонились»), счётчик +1
        │      └─ попыток > N / срочный → «не с кем связаться» (алерт менеджеру)
        └─ «Указать другой контакт» (email, @tg) — если есть
Комментарий клиента → всегда блоком в карточке + первая строка диалога
```

**Права:** «В чат»/«Написать»/«Позвонить» — менеджер; флорист видит состояние и комментарий, счётчик попыток, но писать не может (чаты read-only, см. [[florist-cabinet]]).

## Заметки vs связь

- **Заметка** (`notes` / `addQuickNote`) — внутренняя пометка команды («VIP», «ругался на доставку»). Оставляем как есть.
- **Для отслеживания «не дозвонились»** — компактная строка «Работа с клиентом» в карточке заказа: счётчик попыток + последнее действие + кнопки. История попыток пишется в ленту заказа. Заметки не плодить.
- **Комментарий клиента** — блоком в карточке; при создании диалога становится первой строкой.
