# Кабинет флориста

Отдельный экран-роль для флориста в демо-кабинете Bloom CRM (`docs/demo.html`). Фото-гейт «нужно фото „до"» принадлежит кабинету флориста, а не менеджерскому — фото делает флорист в магазине, менеджеру тост бесполезен.

## Решения (RBAC)

| Аспект | Решение |
|---|---|
| Scope | Только **свой магазин** (не вся сеть) |
| Цикл заказа | От «Принят» до **«В доставке»** — кнопка флориста финальная перед выездом |
| Чаты | **Только чтение** (отвечает менеджер) |
| Витрина | Своего магазина, остатки читаются |
| Отмена | Не отменяет — **«Вернуть менеджеру»** с причиной |
| Фото «после» | Курьер; в демо не обязательное |
| Звук | Нет — только визуальные push + оранжевая подсветка |
| Адаптив | Пока только ПК; после подтверждения КП и оплаты |

## Экраны (меню)

| Экран | Видимое | Отличия от менеджера |
|---|---|---|
| **Заказы** | Заказы своего магазина | Нет счетов/аналитики/оплат; вкладка «Мои в процессе»; сорт по дедлайну, ⚡ сверху, оранжевая подсветка за 45 мин |
| **Чаты** | Только чтение | Нет ввода/шаблонов/заметок; «ждёт ответа» видно, отвечает менеджер |
| **Номенклатура** | Витрина своего магазина (остатки) | Нет цен/скидок/синхронизации |

Скрыты: Счета, Отчёты, Настройки, Команда, Почта, Обращения. «Сегодня» не возвращаем (убрано из сборного; всё в «Заказы»).

## Карточка заказа

Состав + слот, ⚡ срочность, **подсветка за 45 мин до дедлайна**, индикатор времени сборки, получатель/адрес, открытка, комментарий, крупный блок фото, кнопки «Начал сборку» → «Собрано» → «Передать курьеру»/«Готов к самовывозу», «Запросить замену», «Вернуть менеджеру» с причиной. Нет: оплаты, счетов, полной истории.

## Поток

```
Принят (менеджер/авто)
  → «Заказы» (сорт ⚡ → дедлайн)
  → «Начал сборку» (блокировка: «Уже собирает <имя>»)
  → чекбокс «Все цветы в наличии» (нет → «Запросить замену»)
  → «Собрано» → фото «до» (сырые цветы)
  → чекбокс «Брак при сборке» (опционально → аналитика потерь)
  → «Передать курьеру» ИЛИ «Готов к самовывозу»
  → заказ уходит из очереди
```

Не может собрать → «Вернуть менеджеру» + причина → из очереди, уведомление менеджеру. «Испорчено при сборке» → возврат в очередь как «Пересборка» (без уведомления курьеру и +15 мин).

## Фото-гейт

Фото «до» — часть шага флориста (не тост менеджеру). Кнопка «Передать курьеру» заблокирована без фото — подсказка в карточке. Предупреждение «Фото низкого качества — переснять?» с возможностью пропустить.

## Уведомления (визуально, без звука)

1. «Новый заказ в ваш магазин» (с пометкой срочности)
2. **«Заказ приближается к слоту, а фото нет»** — за 45 мин, оранжевая подсветка (раньше спамило менеджера)
3. «Менеджер вернул заказ на доработку»
4. Перегруз >15 заказов → «Рекомендуем режим „Только сборка"»

## Краевые случаи (в демо — 4)

| Ситуация | Действие |
|---|---|
| Цветок закончился, замены нет | «Невозможно собрать» → «Требуется звонок клиенту», из очереди, уведомление менеджеру |
| Клиент отменил при сборке | Карточка серая «ОТМЕНЁН · подтвердите, что не собираете» |
| Нет заказов | Экран «тишина» + кнопка «Позвать менеджера» |
| Размытое фото | Предупреждение «Переснять?» с возможностью пропустить |

## Не делаем в демо (YAGNI)

Полное списание инвентаря · ИИ-сравнение фото с составом · офлайн-кэш · курьерское приложение · подзадачи на 2 букета · «передать коллеге» при обеде · авто-+15 мин курьеру · фото «после» · звук · мобильный адаптив.
